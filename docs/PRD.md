# Product Requirements Document (PRD)

> 文档版本 v0.1 · 最后更新 2026-06-11 · 状态:PM 已确认,进入开发

## 1. 概述

### 1.1 一句话定位

discosweb-visualizer 是一个**零门槛的自助式数据可视化 Web 应用**,用户上传数据,拖拽字段,秒出图表。

### 1.2 目标用户

| 画像 | 痛点 | 我们的解法 |
|------|------|-----------|
| **运营/市场人员** | Excel 出图丑、需要 BI 权限 | 浏览器一键出图,无登录 |
| **数据分析师** | 重复 ETL + 写 SQL 太慢 | 拖拽即聚合,字段自动识别 |
| **产品经理** | 看板工具贵、学习曲线陡 | 免费、PWA、看板模板 |

### 1.3 不做什么 (Out of Scope, v1.0)

- 多用户协作、权限管理、SSO
- 数据库直连 (MySQL/Postgres) — 仅文件上传
- AI 自动洞察
- 移动端原生 App (PWA 已覆盖)
- 实时数据流 (Kafka/WebSocket)

## 2. 核心场景

### 场景 A: 快速出图

1. 用户拖拽 `sample-sales-2025.csv` 到上传区
2. 系统 1s 内识别 8 个字段 (date/region/category/product/channel/revenue/quantity/customer_id)
3. 用户把 `date` 拖到 X 轴,`revenue` 拖到 Y 轴,`region` 拖到颜色分组
4. 系统 200ms 内渲染折线图,显示各区域月度销售趋势
5. 用户点击「导出 PNG」,下载图表

### 场景 B: 销售看板

1. 用户基于场景 A 的图,新建看板
2. 拖入 4 个图表: 区域销售额 (柱状)、品类占比 (饼图)、月度趋势 (折线)、TOP 10 产品 (表格)
3. 保存为「2025 年度销售看板」模板
4. 下次再上传同结构 CSV,一键复用看板

## 3. 功能需求

### 3.1 P0 (v1.0 必上)

| # | 功能 | 验收标准 |
|---|------|---------|
| F1 | 文件上传 | 支持 CSV/JSON/Excel,≤ 50MB 客户端解析 |
| F2 | 字段类型推断 | 上传后 1s 内展示推断结果,允许手动覆盖 |
| F3 | 8 种基础图表 | 折线/柱状/条形/饼图/散点/面积/雷达/漏斗 |
| F4 | 看板模式 | 2x2 / 3x2 网格,拖拽重排 |
| F5 | 模板保存 | 看板可保存为 JSON,导出 + 导入 |
| F6 | 图表导出 | PNG (2x DPI) / SVG / PDF |
| F7 | PWA 离线 | 二次访问无网可用 |
| F8 | 响应式 | 1440 / 1024 / 768 / 375 断点 |

### 3.2 P1 (v1.1+)

- F9: 数据筛选 (字段级)
- F10: 仪表盘嵌入 (iframe / share link)
- F11: 多数据集 JOIN
- F12: 暗色模式

### 3.3 P2 (v2.0+)

- F13: AI 字段映射建议
- F14: 实时协作 (CRDT)
- F15: 服务端大文件处理 (>50MB)

## 4. 非功能需求

| 类别 | 指标 |
|------|------|
| 性能 | 首屏 < 2.5s (LCP), 图表渲染 < 500ms (5k 点) |
| 兼容性 | Chrome 100+, Firefox 100+, Safari 15+, Edge 100+ |
| 可访问性 | WCAG 2.1 AA, 键盘可达, 屏幕阅读器友好 |
| 安全 | CSP nonce, 无 XSS 入口, 不收集 PII |
| 隐私 | 数据默认本地存储, 不上传服务器 |

## 5. 度量指标

### 5.1 北极星

**每周生成图表数** (周活用户 × 人均图表数)

### 5.2 辅助指标

- 上传 → 首图转化率 (目标 > 70%)
- 看板保存率 (目标 > 15%)
- PWA 安装率 (目标 > 8%)

## 6. 风险与缓解

| 风险 | 影响 | 缓解策略 |
|------|------|---------|
| 浏览器解析 50MB+ Excel 卡顿 | 高 | 降级到服务端解析,加进度条 |
| ECharts 大数据点卡顿 | 中 | 引入 Web Worker + LTTB 降采样 |
| 字段推断误判 | 中 | 允许手动覆盖,记忆用户选择 |
| IndexedDB 配额满 | 低 | 提示用户清理 / 引导下载数据 |
