# Roadmap

> 4 周迭代计划,从零到 v1.0 GA。每周末做一次 Demo + 回顾。

## Week 1: 脚手架 + 文件上传 + 字段识别

**目标**: 跑通「上传 CSV → 看到字段列表」最小闭环。

### 交付物

- [x] 仓库初始化 (frontend + backend + docker-compose)
- [ ] 前端 Vite + React + TS 脚手架,目录结构按特性组织
- [ ] 后端 FastAPI 项目结构,`/upload` `/infer-types` 端点
- [ ] 文件上传 UI (Drag & Drop),支持 CSV/JSON/Excel
- [ ] 客户端解析: CSV (PapaParse) / JSON (原生) / Excel (SheetJS)
- [ ] 字段类型推断引擎 (维度/度量/时间/文本)
- [ ] 字段列表展示,允许手动覆盖类型
- [ ] `data/sample-sales-2025.csv` 加载为默认数据
- [ ] 端到端冒烟测试 (Playwright)

### Demo

- 上传 `sample-sales-2025.csv` → 看到 8 个字段 + 推断类型

## Week 2: 图表引擎 (8 种基础图表)

**目标**: 拖拽字段 → 出图,8 种图表全覆盖。

### 交付物

- [ ] 图表画布组件 (ECharts wrapper)
- [ ] 字段面板: 拖拽到 X / Y / 颜色 / 尺寸 / 工具提示
- [ ] 8 种图表:
  - [ ] 折线图 (line)
  - [ ] 柱状图 (bar, 垂直 + 水平)
  - [ ] 饼图 (pie) + 环形图 (donut)
  - [ ] 散点图 (scatter)
  - [ ] 面积图 (area)
  - [ ] 雷达图 (radar)
  - [ ] 漏斗图 (funnel)
  - [ ] 桑基图 (sankey)
- [ ] 图表配置侧栏: 标题、颜色主题、坐标轴、图例位置
- [ ] 智能图表推荐: 根据字段类型自动选默认图表
- [ ] 图表类型切换 (一键互转)
- [ ] 单元测试: 字段映射 → ECharts option 转换
- [ ] 视觉回归测试 (Playwright 截图对比)

## Week 3: 看板 + 模板保存

**目标**: 多图拼成看板,保存为可复用模板。

### 交付物

- [ ] 看板画布: 2x2 / 3x2 / 自由布局 三种网格
- [ ] 拖拽图表到看板 cell
- [ ] 看板 cell 拖拽重排 + 调整大小
- [ ] 看板模板: 保存为 JSON (含数据集引用)
- [ ] 模板导入 / 导出 (文件)
- [ ] 模板库: 内置 3 套示例模板 (销售 / 财务 / 运营)
- [ ] URL hash 同步看板状态 (可分享)
- [ ] 看板缩略图预览
- [ ] 单元测试: 看板序列化 / 反序列化
- [ ] E2E 测试: 创建看板 → 导出 → 重新导入

## Week 4: 导出 + PWA + 优化

**目标**: 生产级打磨,性能达标,离线可用。

### 交付物

- [ ] 图表导出:
  - [ ] PNG (2x DPI,带白底)
  - [ ] SVG (矢量,带字体嵌入)
  - [ ] PDF (含数据表)
- [ ] PWA:
  - [ ] manifest.json + icons
  - [ ] Service Worker (vite-plugin-pwa)
  - [ ] 离线访问已上传数据集
  - [ ] 安装提示
- [ ] 性能优化:
  - [ ] 路由懒加载
  - [ ] ECharts 按需引入 (按图表类型)
  - [ ] 大数据集降采样 (LTTB)
  - [ ] 关键 CSS 内联
- [ ] 可访问性:
  - [ ] 键盘导航
  - [ ] ARIA 标签
  - [ ] 色彩对比度 ≥ 4.5:1
  - [ ] prefers-reduced-motion
- [ ] 响应式断点测试: 320 / 768 / 1024 / 1440 / 1920
- [ ] 跨浏览器测试: Chrome / Firefox / Safari / Edge
- [ ] Lighthouse 分数: Performance > 90, Accessibility > 95
- [ ] 完整 README + 用户文档
