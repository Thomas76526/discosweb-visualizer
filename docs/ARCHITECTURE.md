## 关键设计决策

### 1. 本地优先 (Local-First)

- 上传数据存于浏览器 IndexedDB,不强制走后端
- 后端**仅在**以下场景介入:
  - 文件 > 50MB 需要服务端流式解析
  - 用户希望用服务端算力做聚合 (Polars)
  - 用户希望跨设备同步 (未来)

### 2. 字段类型自动推断

| 输入特征 | 推断类型 | 处理方式 |
|---------|---------|---------|
| 字符串,基数 ≤ 50 | 维度 (dimension) | 用于分组、颜色映射 |
| 字符串,基数 > 50 | 文本 (text) | 不进图表,仅展示 |
| 数字,取值唯一数 ≤ 20 | 度量 (measure,有序) | 时间轴优先 |
| 数字,取值唯一数 > 20 | 度量 (measure,连续) | 数值轴 |
| ISO 8601 日期字符串 | 时间 (temporal) | 自动时间轴 |

### 3. 状态分层

| 状态 | 存储 | 同步 |
|------|------|------|
| 上传的数据集 | IndexedDB | 仅本地 |
| 图表配置 | URL hash + IndexedDB | 可分享 |
| 看板布局 | IndexedDB | 仅本地 |
| 用户偏好 (主题/语言) | localStorage | 仅本地 |

### 4. 渲染性能

- 单图表 < 5k 点: ECharts SVG/Canvas 自由切换
- 单图表 5k-100k 点: Canvas + 采样
- 单图表 > 100k 点: Web Worker + LTTB 降采样

## 模块依赖

```text
frontend/
  components/  →  hooks/  →  store/  →  lib/
                                       ↘  api/
  styles/      (独立,CSS Modules + tokens)
```

## 部署拓扑

```text
docker-compose.yml
  ├── frontend (nginx, port 5173)   → 浏览器
  └── backend  (uvicorn, port 8000)  →  REST
```

无数据库 (P0 阶段),无外部依赖。后续会加 Redis (缓存聚合结果) + Postgres (用户看板云同步)。
